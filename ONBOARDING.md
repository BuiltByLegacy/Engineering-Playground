# Engineering Playground Repository Onboarding

Complete Lemery company onboarding through the Employee Handbook and Lemery OS `/start` before material work. Read `README.md`, Lemery inheritance/security files, experiment/game/simulation architecture, learning objectives, validation expectations, and current issues.

Engineering Playground is a Lemery lab. Experimental work must still preserve security, evidence, authorization, and clear separation between prototype behavior and production-ready claims. Repository access does not imply production credentials, publishing authority, secrets, or admin access.

Validate the approved development environment before work. Start from a bounded GitHub issue or governed experiment with a clear objective and evidence target. First work should favor a small, reviewable implementation rather than broad architectural or distribution changes.

Product-ready means company onboarding/competency complete, Engineering Playground assignment recorded, scoped access verified, repository orientation complete, environment validated, controlled first issue/experiment completed, evidence reviewed successfully, and manager/product-owner sign-off recorded.

Return to Lemery OS `/start` if any gate is missing.
